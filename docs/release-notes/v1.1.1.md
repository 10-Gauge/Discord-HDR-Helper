Discord HDR Helper 1.1.1 fixes Discord streaming the control panel instead of the picture.

## Fixes

- **Discord now shares only the output.** Discord's *Applications* list picks one window per app, and it could pick the control panel, which showed the whole app (settings and all) in the stream even with *Hide this panel from the stream* on. The panel no longer counts as a main window, so the output window is the only one Discord can pick.
- The control panel no longer has its own taskbar button. Click **Discord HDR Helper Output** in the taskbar (or Alt+Tab to it, or right-click the output window) to open the panel. Minimizing the panel tucks it away the same way.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.

If you were already streaming, stop the stream and share **Discord HDR Helper** again from the *Applications* tab.
