Discord HDR Helper 1.1.7 fixes the stream being too dark in 1.1.6.

## Fixes

- **Normal brightness in the stream.** 1.1.6 switched the output window to an HDR format, which Discord reads as if it were SDR, so the stream came out very dark. The output is a normal SDR window again. To stop Discord from washing it out, the picture is darkened by exactly the amount Discord brightens it (your Windows *SDR content brightness* level), so the two cancel out. A light dither keeps gradients smooth.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.
