The first release of Discord HDR Helper. It fixes the bright, washed-out picture Discord sends when you share your screen with Windows HDR turned on.

## Download

Download **DiscordHDRHelper.exe** below and run it. There's nothing to install. The exe isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.

**Requirements:** Windows 10 version 2004 or newer (Windows 11 recommended), and a GPU with Direct3D 11 support.

## How to use it

1. Pick a display or a window in the app.
2. In Discord, start a screen share, open the **Applications** tab and choose **Discord HDR Helper Output**.
3. Adjust **Brightness** if the stream looks too bright or too dark.

## Features

- HDR → SDR tonemapping on the GPU using the BT.2390 curve, plus Reinhard and Clip
- Brightness that follows the Windows *SDR content brightness* slider and your display's peak, by default
- Live preview of exactly what Discord receives
- Capture a whole display or a single window
- Output window that stays behind your other windows, and a control panel that hides itself from screen capture
- Light on resources: frames stay on the GPU the whole way through
