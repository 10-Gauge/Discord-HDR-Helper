Discord HDR Helper 1.1.5 streams at full resolution, whatever size your screen is.

## Fixes

- **Sharp stream at any window size.** Discord records a window at its size on screen, so a smaller output window gave a blurry, jagged stream. The output window is now always exactly the source's resolution, and it follows the source if the source changes size. It can be larger than your screen (a 4K game on a 1440p monitor, for example) and stays behind your other windows.
- The output window can no longer be resized by dragging its edges, and the *Resize output to source* button is gone, since the size is now always right. You can still drag the window to move it.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.
