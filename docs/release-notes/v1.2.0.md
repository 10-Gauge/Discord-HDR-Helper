Discord HDR Helper 1.2 changes how the output window draws, so Discord streams it like any normal window.

## What's new

- **The output looks right in the stream.** Discord treated the helper's output like a game and ran its own HDR processing on it, which made the stream too dark or washed out depending on settings. The output now draws the same way a web browser does, so Discord captures it like a normal window and leaves the colors alone.
- **Simpler Stream brightness.** It now starts at 100% (no change), and you lower it only if the stream looks too bright. The automatic mode, which guessed at Discord's processing, is gone.

## Tips

- Keep the output window on your **HDR** display. With an HDR display connected, Discord streams windows on an SDR monitor too dark, for any app.
- If a game streams too bright even without the helper, turn off **Auto HDR** in Windows Settings > System > Display > HDR. It turns SDR games into HDR.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.
