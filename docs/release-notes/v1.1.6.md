Discord HDR Helper 1.1.6 fixes the washed-out colors when sharing the output window, and a crash on Stop.

## Fixes

- **Correct colors when sharing the output window.** On an HDR display, Windows brightens normal windows to your *SDR content brightness* level, and Discord recorded that brightened picture, which washed the stream out again. The output window is now drawn at a fixed 80-nit white, which Windows leaves alone, so viewers get the picture as tonemapped. The output window looks dim on your own screen; that's expected.
- **No more crash when you click Stop** or switch to another source.
- The control panel's window is now called **Discord HDR Helper Settings**, so in Discord's *Applications* list it's clear that **Discord HDR Helper Output** is the one to share.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.

Set Windows' *SDR content brightness* back to where you like it; the stream no longer depends on it.
