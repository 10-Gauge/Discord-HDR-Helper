Discord HDR Helper 1.1.2 is a second fix for Discord streaming the control panel instead of the picture.

## Fixes

- **Discord now gets only the output picture.** Discord's application share hooks the graphics output of the app you pick, much like game capture, and it was grabbing the control panel's frames. Window settings such as *Hide this panel from the stream* can't stop that. The control panel now draws without the graphics path that Discord hooks, so the output window is the only picture left for Discord to grab.
- The control panel has its own taskbar button again. 1.1.1 removed it, which didn't help.

## Download

Download **DiscordHDRHelper.exe** below. There's nothing to install. If SmartScreen warns you, click **More info**, then **Run anyway**.

If you were already streaming, quit the old version, stop the stream, then share **Discord HDR Helper** again from the *Applications* tab.
